常见问题

安装时提示「未知来源 / 有风险」怎么办？
这是安卓对浏览器直接下载 APK 的常规提示，不代表应用有问题。在系统弹窗里选择「仍要安装 / 允许本次安装」即可。安装包均为开发者本地签名构建，未经过任何第三方改包。
GitHub 下载打不开 / 太慢怎么办？
安装包放在 GitHub Release，国内网络偶尔访问不稳定。若点击后长时间无响应，可加作者 QQ 2208144236 或发邮件到 2208144236@qq.com，作者会直接把安装包发给你；也可以在 Release 页面用其他网络环境重试。
高级功能怎么解锁？需要联网吗？
完全离线。打开应用内「会员中心 / 家庭版会员」，复制本机标识，按页面标示价格扫码付款（首发期内按首发价）后把标识发给作者（QQ 或邮箱），作者回一串激活码，填入即解锁。不需要账号、不需要联网、不上传任何数据。
换手机、卸载重装后还在吗？
激活码与本机标识绑定，换设备需要重新发标识，联系作者补发即可，不额外收费。卸载前建议先在应用内做本地备份 / 导出，数据只存本机。
三款可以一起买吗？
可以。三件打包 39 元（单买合计 56 元，省 17 元）。付款时备注「三件打包」，把三款应用会员中心里各自的本机标识一起发给作者，作者会一次性回三个激活码。激活码按设备分别生成，换设备仍可免费补发。
为什么坚持不联网？
隐私相册、个人题库、服药记录都属于最敏感的个人信息。不上云就不需要账号、不会有推送广告、也不会因为服务关停而丢数据；代价是没有云同步，我们把这个选择权明确交给你。
