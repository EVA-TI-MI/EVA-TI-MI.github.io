小游戏合集 - 霓虹贪吃蛇 & 笔趣阁小说阅读

🎮 在线小游戏合集

这里收录了两个自制的网页小游戏，均为纯前端实现，无需安装，打开即玩。

🐍 霓虹贪吃蛇（单机版）

经典贪吃蛇游戏的霓虹像素重制版，功能丰富：

  • 登录系统：本地注册登录，保存个人最高分
  • 排行榜：与本地玩家比拼分数
  • 三种难度：简单 / 普通 / 困难，影响初始速度
  • 三种地图大小：小(40×30) / 中(60×40) / 大(80×50)
  • 边界模式：撞墙死亡 或 穿墙模式
  • 金苹果：随机出现，吃到得 30 分
  • 8种蛇皮肤：翠绿、烈焰、金光、碧海、橙霞、青霜、紫电、彩虹
  • 音效系统：吃食物、金苹果、转向、游戏结束音效
  • 操作方式：方向键 / WASD 控制，空格暂停，C 切换皮肤
  • 手机支持：触屏方向键 + 暂停/换色按钮
  • PWA支持：安卓手机可”添加到主屏幕”像APP一样离线运行

👉 点击开始玩贪吃蛇

📚 笔趣阁小说阅读

一个精美的在线小说阅读器，包含：

  • 三国演义全文：120回完整内容，59.2万字（公版书，合法阅读）
  • 内置书库：玄幻、仙侠、都市、历史、科幻、悬疑、古典等分类
  • 阅读功能：4种阅读主题（护眼/夜间/纸张/深夜）、字体大小调节
  • 有声书朗读：多音色切换（男女声）、5档语速、逐段高亮、自动连播下一章，支持离线听书
  • 章节目录：快速跳转任意章节
  • 书架功能：本地收藏，自动记录阅读进度
  • 搜索功能：按书名、作者、标签搜索
  • 数据来源：Python爬虫自动采集公版小说，错字自动修正

👉 点击进入笔趣阁

📦 下载桌面版

贪吃蛇还提供了 Windows 桌面版（EXE），无需浏览器即可运行：

  • 文件位置：D:\tanlan\dist\霓虹贪吃蛇.exe
  • 基于 Python + WebView2 打包，单文件约 14MB

📱 安卓手机安装方法

贪吃蛇支持 PWA，在安卓手机上：

  1. 用 Chrome 浏览器打开 贪吃蛇页面
  2. 点击浏览器菜单（右上角三个点）
  3. 选择”添加到主屏幕”
  4. 桌面会出现游戏图标，点击即可全屏运行，支持离线游戏

如需 APK 安装包，可使用微软的 PWABuilder 在线工具，输入游戏网址即可免费生成 APK。
